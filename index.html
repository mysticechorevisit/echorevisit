About the EchoRevisit Uploader

The EchoRevisit Uploader is a private tool used only by the channel owner. It uses the YouTube Data API to upload EchoRevisit's own finished videos, titles, descriptions and thumbnails to the EchoRevisit channel. It is not offered to the public and does not access any other user's account or data.
