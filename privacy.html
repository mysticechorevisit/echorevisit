Privacy Policy

EchoRevisit Uploader · Last updated 3 November 2026

This policy covers the EchoRevisit Uploader ("the app"), a private tool the owner of the EchoRevisit YouTube channel uses to publish videos to that channel.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What the app accesses

  • When the channel owner signs in with Google, the app receives an access token that lets it upload videos and thumbnails to, and read the recent upload list of, the owner's own channel.
  • It reads the channel's recent upload titles only to avoid posting the same video twice.
  • It does not access, collect or store data about any other YouTube user, viewer, subscriber or commenter.

How data is stored and shared

  • The access token is stored only on the channel owner's own computer. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, or used for advertising.
  • The app does not use cookies or analytics, and this website does not either.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page. Deleting the token file from the owner's computer removes all stored data. Questions or deletion requests: mysticecho.revisit@gmail.com.

Changes

Updates to this policy will be posted on this page with a new date.
